# Word for Responsa

מאקרו VBA שמחבר בין Microsoft Word לבין פרויקט השו״ת של בר־אילן. הגרסה הראשונה מספקת חיפוש של טקסט מסומן ב-Word, ישירות בחלונות החיפוש של פרויקט השו״ת.

## מה כלול בגרסה הראשונה

המודול [`src/BarIlanSearch.bas`](./src/BarIlanSearch.bas) כולל שתי פעולות:

- `SearchSelectionInBarIlan` — מעביר את המילים בעברית שנבחרו ב-Word לחיפוש הקל.
- `SearchSelectionAdvancedInBarIlan` — בונה שאילתת חיפוש מתקדם מהמילים שנבחרו ומעביר אותה לחיפוש המתקדם.

הקוד מאתר את חלון החיפוש הגלוי, מעביר אותו למצב החיפוש המבוקש, ממלא את תיבת החיפוש ומודיע לתוכנה על שינוי הטקסט לפני הפעלת החיפוש. שימוש בחלון מוסתר עלול להציג את השאילתה החדשה בלי לעדכן את מצב החיפוש הפעיל, ולכן המודול אינו מפעיל עוד חלונות חיפוש מוסתרים. בחירה לא רציפה ב-Word נתמכת באמצעות העתקת הבחירה ללוח. לפני השימוש, המודול מנקה את הטקסט ומשאיר עד עשר מילים בעברית; ניקוד וסימנים שאינם חלק מהשאילתה מוסרים. בחיפוש מתקדם כל מילה נעטפת בתחילית ובסיומת המוגדרות במודול, ומרחק `30:` נוסף כשיש יותר ממילה אחת.

## דרישות והתקנה

- Windows, Microsoft Word 2010 ומעלה, ו-VBA7.
- פרויקט השו״ת מותקן וזמין. ברירת המחדל היא לזהות חלון של תהליך `RESPONSA.exe` שכבר פועל.
- לייבוא: פותחים את עורך VBA ב-Word (`Alt+F11`), בוחרים **File > Import File...** ומייבאים את `src/BarIlanSearch.bas`.
- יש לשמור את המאקרו במסמך Word מסוג `.docm` או בתבנית `Normal.dotm`, בהתאם למקום שבו רוצים שיהיה זמין.
- כדי להפעיל בקיצור מקשים: ב-Word פותחים **File > Options > Customize Ribbon > Keyboard shortcuts: Customize...**, בוחרים בקטגוריית **Macros**, מסמנים את המאקרו הרצוי ומקצים לו קיצור שאינו מתנגש עם קיצור קיים.
- אפשר להגדיר במודול את `RESPONSA_PATH` לנתיב המלא של `RESPONSA.exe` אם רוצים שהמאקרו יוכל להפעיל את התוכנה כאשר היא אינה פועלת.

לאחר ההתקנה, מסמנים טקסט ב-Word ומפעילים את המאקרו או את קיצור המקשים שהוקצה לו. ההפעלה דורשת שחלונות החיפוש ותוויותיהם יתאימו לממשק פרויקט השו״ת שעבורו נכתב המודול. מזהי כפתורי המעבר בין חיפוש קל למתקדם נבדקו מול ממשק פרויקט השו״ת גרסה 29; יש לאמת אותם מחדש מול מהדורות אחרות.

## מפת דרכים

1. **חיפוש מתוך Word בקיצור מקשים** — תשתית המודול ופקודות החיפוש הקל והמתקדם כלולות בגרסה הראשונה.
2. **שליחת הטקסט המסומן לחיפוש קל** — כלולה.
3. **שליחת הטקסט המסומן לחיפוש מתקדם** — כלולה.
4. **חיפוש טבלאי** — אפשרות עתידית; אינה ממומשת בגרסה הראשונה.
5. **שליחת טקסט לעיון במקורות** — אפשרות עתידית; אינה ממומשת בגרסה הראשונה.

המאגר מתעד את מצב הקוד בפועל. תאימות לגרסאות שונות של Word ופרויקט השו״ת, ובפרט יציבות הפעולה בכל סביבה, דורשות בדיקה בסביבת היעד.
