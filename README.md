# Word for Responsa

מאקרו VBA שמחבר בין Microsoft Word לבין פרויקט השו״ת של בר־אילן. הוא מאפשר לחפש טקסט מסומן בחיפוש הקל, בחיפוש המתקדם ובעמוד «כתיבת מקורות» שבחלון «עיון».

## מה כלול

המודול [`src/BarIlanSearch.bas`](./src/BarIlanSearch.bas) כולל שלוש פעולות:

- `SearchSelectionInBarIlan` — מעביר את המילים בעברית שנבחרו ב-Word לחיפוש הקל.
- `SearchSelectionAdvancedInBarIlan` — בונה שאילתת חיפוש מתקדם מהמילים שנבחרו ומעביר אותה לחיפוש המתקדם.
- `SearchSelectionInBarIlanCitation` — מעביר את הטקסט שנבחר ב-Word לתיבת החיפוש בעמוד «כתיבת מקורות» בחלון «עיון» ומפעיל את החיפוש. הטקסט נשמר כפי שנבחר, פרט לאיחוד מעברי שורה ורווחים.

פקודות החיפוש מאתרות את חלון החיפוש הגלוי, מעבירות אותו למצב המבוקש, ממלאות את תיבת החיפוש ומודיעות לתוכנה על שינוי הטקסט לפני הפעלת החיפוש. פקודת «עיון» פותחת או מאתרת את חלון «עיון», בוחרת בעמוד «כתיבת מקורות», ממלאת את התיבה ומפעילה את החיפוש — ללא שימוש בקטלוג הספרים. בסיום, היא מחזירה את פרויקט השו״ת לחזית ומשאירה את חלון «עיון» ואת תיבת «כתיבת מקורות» בפוקוס, כדי לאפשר המשך עבודה ידני. שימוש בחלון חיפוש מוסתר עלול להציג שאילתה בלי לעדכן את מצב החיפוש הפעיל, ולכן המודול אינו מפעיל חלונות חיפוש מוסתרים. בחירה לא רציפה ב-Word נתמכת באמצעות העתקת הבחירה ללוח. חיפוש קל ומתקדם מנקים את הטקסט ומשאירים עד עשר מילים בעברית; ב«עיון» הטקסט נשמר, למעט איחוד מעברי שורה ורווחים. בחיפוש מתקדם כל מילה נעטפת בתחילית ובסיומת המוגדרות במודול, ומרחק `30:` נוסף כשיש יותר ממילה אחת.

## דרישות והתקנה

- Windows, Microsoft Word 2010 ומעלה, ו-VBA7.
- פרויקט השו״ת מותקן וזמין. המאקרו מזהה חלון של `RESPONSA.exe` שכבר פועל; אם התוכנה אינה פועלת, ניתן להגדיר את משתנה הסביבה `RESPONSA_PATH` עם הנתיב המלא לקובץ `RESPONSA.exe` כדי שהמאקרו יפעיל אותה.
- לייבוא: פותחים את עורך VBA ב-Word (`Alt+F11`), בוחרים **File > Import File...** ומייבאים את `src/BarIlanSearch.bas`.
- יש לשמור את המאקרו במסמך Word מסוג `.docm` או בתבנית `Normal.dotm`, בהתאם למקום שבו רוצים שיהיה זמין.
- כדי להפעיל בקיצור מקשים: ב-Word פותחים **File > Options > Customize Ribbon > Keyboard shortcuts: Customize...**, בוחרים בקטגוריית **Macros**, מסמנים את המאקרו הרצוי ומקצים לו קיצור שאינו מתנגש עם קיצור קיים.
- להגדרת `RESPONSA_PATH` ב-Windows: פותחים **עריכת משתני סביבה עבור החשבון**, מוסיפים משתנה משתמש בשם `RESPONSA_PATH` וערך שהוא הנתיב המלא לקובץ `RESPONSA.exe` בהתקנה המקומית, ואז מפעילים מחדש את Word. אין צורך להגדיר את הנתיב בקוד. אם פרויקט השו״ת כבר פועל, המאקרו יאתר אותו גם ללא המשתנה. המאקרו אינו בודק אות כונן או מיקום של מאגרי הספרים.

לאחר ההתקנה, מסמנים טקסט ב-Word ומפעילים את המאקרו או את קיצור המקשים שהוקצה לו. ההפעלה דורשת שחלונות החיפוש ותוויותיהם יתאימו לממשק פרויקט השו״ת.
## מפת דרכים

1. **חיפוש מתוך Word בקיצור מקשים** — תשתית המודול ופקודות החיפוש הקל והמתקדם כלולות בגרסה הראשונה.
2. **שליחת הטקסט המסומן לחיפוש קל** — כלולה.
3. **שליחת הטקסט המסומן לחיפוש מתקדם** — כלולה.
4. **חיפוש טבלאי** — אפשרות עתידית.
